三、登记范围与条数
------------------
素材根目录：`src/main/resources/craftengine/farmersdelight/resourcepack/assets/farmersdelight`

扫描 752 个文件，其中 **423 个登记为搬运素材**：

* `status: "ported"` —— 343 个：与上游同相对路径的文件**逐字节相同**（贴图 329、音效 14）。
* `status: "modified"` —— 80 个：上游同相对路径存在该文件，但本仓库改写过
  （`models/block` 59、`lang` 17、`models/item` 3、`textures/gui` 1）；每条同时记录本仓库 `sha256`
  与上游 `upstream_sha256`。

其余 **329 个为自制/转换素材**（`models` 276、`textures` 51、`items/skillet_cooking.json`、`sounds.json`）：
上游不存在同相对路径的文件，因此不登记，只在 `ASSET-ORIGINS.json` 的 `self_authored` 里给出计数与分布。

不在本清单范围内（因此也不逐个登记）：
* CraftEngine 配置 YAML（`src/main/resources/craftengine/**/configuration/**`）——为本插件编写的数据，
  与上游 Java/JSON 没有逐字节对应关系；
* 插件自身 Java 源码、datapack 定义、服务端 `lang/*.yml`；
* shade 进 jar 的 AntiGriefLib 与 bStats（已在 `NOTICE.md` 登记）。

四、逐条清单
------------
`ASSET-ORIGINS.json`（同目录）逐条登记：`path`（相对本插件仓库根）、`asset`（素材根内相对路径）、
`upstream`、`repo`、`commit`、`license`、`status`、`sha256`（当前文件内容），`modified` 条目另有
`upstream_sha256`。清单由脚本按文件内容生成，不含时间戳，因此可重复生成且结果一致。

五、校验方法
------------
```
python tools/gen_asset_origins.py            # 只读；重算 SHA-256 比对清单，漂移时退出码 1
python tools/gen_asset_origins.py --write    # 重新生成 ASSET-ORIGINS.json
```

`--check` 会报告四类漂移：`CHANGED`（已登记文件内容变了）、`MISSING`（已登记文件不见了）、
`UNREGISTERED`（磁盘上出现与上游匹配但未登记的文件）、`PIN-MOVED`（上游检出 HEAD 与钉住的提交不一致）。
素材改动后必须重跑 `--write` 并复核上游归属。
